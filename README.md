# 🚦 Smart Traffic Management System

A Java-based **Smart Traffic Management System** developed using **IntelliJ IDEA**. This project simulates and manages traffic signals efficiently, helping improve traffic flow and reduce congestion through intelligent signal control.

## 📌 Features

- 🚥 Traffic signal management
- 🚗 Vehicle flow simulation
- ⏱️ Automatic traffic light timing
- 👮 Traffic monitoring
- 📊 User-friendly graphical interface (if applicable)
- 💾 Data management
- ⚠️ Input validation and exception handling

- Java Swing (GUI)

## 🚀 Getting Started

### Prerequisites

- Java JDK 8 or later
- IntelliJ IDEA

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Zohaib-Abdulislam/SmartTrafficManagementSystem.git
```

2. Open **IntelliJ IDEA**.

3. Select:

```
File → Open
```

4. Choose the `SmartTrafficManagementSystem` folder.

5. Wait for IntelliJ to index the project.

6. Make sure the JDK is configured:

```
File → Project Structure → Project SDK
```

7. Run the project by executing the `Main.java` file.

## ▶️ Running the Project

- Open the project in IntelliJ IDEA.
- Locate `Main.java`.
- Right-click on the file.
- Click **Run Main.main()**.
